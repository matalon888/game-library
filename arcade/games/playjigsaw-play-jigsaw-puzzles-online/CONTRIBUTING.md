# Contributing to Play Jigsaw Puzzles Online

Thank you for your interest in contributing to **Play Jigsaw Puzzles Online**! This open-source web project aims to provide a lightweight, accessible HTML5 jigsaw puzzle experience for puzzle lovers worldwide, brought to you by [PlayJigsaw.net](https://playjigsaw.net/).

## Code of Conduct

We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone. Please be respectful and courteous in all interactions.

## How Can You Contribute?

### 1. Reporting Bugs
- Check the [GitHub Issues](https://github.com/playjigsaw/play-jigsaw-puzzles-online/issues) tracker before creating a new issue to avoid duplicates.
- Describe the bug clearly with reproduction steps, your browser version, and OS.

### 2. Suggesting Enhancements
- Propose new puzzle cuts, animations, UI improvements, or audio soundscapes.
- Open an issue titled `[Feature Request]: <Your idea>`.

### 3. Pull Requests (PRs)
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/amazing-feature`.
3. Make your changes using clean Vanilla JavaScript, CSS, and semantic HTML.
4. Test locally in modern browsers (Chrome, Firefox, Safari, Edge).
5. Commit your changes: `git commit -m 'feat: add custom puzzle piece shapes'`.
6. Push to your branch: `git push origin feature/amazing-feature`.
7. Open a Pull Request on GitHub.

## Development Setup

No complex build pipeline is required! Simply clone the repo and open `index.html` in your browser or run:

```bash
npx serve .
```
