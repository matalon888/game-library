# 🧠 Memory Match

A card-flipping memory game. Flip two cards at a time to find matching pairs — clear the board in as few moves as possible!

## ▶️ How to play

Just **double-click `index.html`** — it opens in your browser. No installation needed.

- Click a card to flip it, then flip a second one.
- If they match, they stay face-up. If not, they flip back.
- Find all **8 pairs** to win.
- Your **moves** and **time** are tracked — try to beat your own record.

## ✨ Features

- ⏱️ Live move counter and timer
- 🎴 Smooth 3D card-flip animation
- 🎉 Win summary with your stats
- 📱 Responsive layout
- ⚡ Zero dependencies — one single HTML file

## 🛠️ Built with

Plain **HTML, CSS, and JavaScript**. No frameworks, no build step.

## 🌐 Play online

You can host this for free with **GitHub Pages**: go to the repo's *Settings → Pages*, select the `main` branch, and your game gets a public link.
