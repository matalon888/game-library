# Đóng góp cho Moonbloom Endless

Cảm ơn bạn muốn đóng góp!

1. Fork repository và tạo một branch ngắn gọn.
2. Giữ thay đổi tập trung vào một vấn đề.
3. Chạy `npm test` và `npm run build` trước khi tạo pull request.
4. Với thay đổi gameplay, mô tả cách kiểm thử bằng chuột và cảm ứng.
5. Không thêm asset của bên thứ ba khi chưa ghi rõ nguồn và giấy phép.

Vui lòng dùng GitHub Issues cho bug report và đề xuất tính năng.
