# OpenAI Build Week Rules Summary

Deadline:
- Registration: July 9, 2026 10:00am PT – July 21, 2026 5:00pm PT.
- Submission: July 13, 2026 9:00am PT – July 21, 2026 5:00pm PT.
- Winners announced around August 12, 2026 2:00pm PT.

Project:
- Must build with Codex and GPT-5.6.
- Allowed project types include web/native apps, backend tools, agent plugins/skills/MCPs/tools, and games.
- Must fit one track:
  - Apps for Your Life
  - Work and Productivity
  - Developer Tools
  - Education
- Must run consistently on its intended platform.
- Must be newly created during the submission period, or meaningfully extended during the period if pre-existing.
- Must document Codex/GPT-5.6 usage during the submission period.

Submission:
- Choose the best category.
- Include a text description explaining features and functionality.
- Include a demo video under 3 minutes.
- Demo video must include audio explaining what was built and how Codex/GPT-5.6 were used.
- Demo video must be public on YouTube.
- Do not include third-party trademarks, copyrighted music, or copyrighted material unless permission is granted.
- Provide a code repository URL for judging/testing.
- Repo can be public with relevant licensing or private shared with testing@devpost.com and build-week-event@openai.com.
- README must describe how Codex was used, where Codex accelerated workflow, what key decisions the entrant made, and how GPT-5.6/Codex contributed.
- Provide `/feedback` Codex Session ID for the project thread where most core functionality was built.
- Provide a working project link, functioning demo, or test build free for judging through the judging period.

Judging:
- Stage 1 pass/fail: project must fit the theme and reasonably apply required APIs/SDKs.
- Stage 2 equally weighted:
  - Technological Implementation
  - Design
  - Potential Impact
  - Quality of the Idea

IP:
- Submission must be original work and owned by entrant/team/org.
- Open-source software is allowed if licenses are followed.
- Third-party SDKs/APIs/data require authorization and license compliance.
