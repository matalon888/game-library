# RAINCOIL contributor guidance

Canvas/Web Audio source is shared by the browser and Electron Windows targets. Keep rules in src/engine.js independent of DOM/rendering. Game assets are procedural; the launcher icon is generated by tools/make-icon.mjs. No external runtime network requests.

Read README.md, docs/BUILD.md and docs/ENGINE.md before changing behavior. Preserve standard-mode compatibility unless intentionally changing it; keep records separate by type, duration and pace. Run npm test and relevant browser checks. Automated survival is not evidence of fun or accessibility.

Keep builds, dependency caches, screenshots, promotional art and generated test evidence out of Git. Use .cache/ for local work. Preserve the game credits and MIT/third-party notices. Do not commit credentials or personal environment paths. Publication and other external actions require an explicit maintainer request.
