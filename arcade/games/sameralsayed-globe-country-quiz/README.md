# Globe Country Quiz 3D

🌍 **Title:** Globe Country Quiz 3D  
📝 **Description:** An original responsive WebGL geography game where players rotate a 3D globe, inspect a highlighted location, and guess the country using hints, scoring, and timed rounds.  
🏷️ **Tags:** webgl, 3d-game, geography-game, country-quiz, educational-game, html5, css3, javascript, jquery, bootstrap, mobile-game, seo  
🔑 **Keywords:** 3D country guessing game, WebGL globe quiz, educational geography game, mobile-friendly HTML5 game, JavaScript world quiz, browser learning game  

## Features

🎮 Interactive 3D globe rendered with WebGL  
🌐 Highlighted country target on a rotating Earth  
⌛ Timed rounds with score, streak, and accuracy tracking  
💡 Hint system with continent, first-letter, and clue support  
📱 Mobile-friendly responsive layout for phones, tablets, and desktops  
🧠 Educational gameplay focused on geography learning  
🎨 Modern interface built with CSS3 and Bootstrap  
⚙️ jQuery-powered form handling and game UI updates  
🔍 SEO-ready metadata with Open Graph, Twitter tags, and JSON-LD  
🪪 Footer credit for SAMER SAEID with custom link and copyright text
