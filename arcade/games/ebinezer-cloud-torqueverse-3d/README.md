## 🎮 About The Project

**TorqueVerse 3D** is a browser-based arcade driving game designed to deliver a lightweight yet immersive 3D driving experience directly on the web.

Built using **Three.js and modern JavaScript**, the project combines driving physics, AI opponents, traffic systems, pedestrians, collectibles, stunt mechanics, destructible objects, multiple environments and customizable graphics settings.

No traditional game engine is required.

Just open the game in a modern browser and enter the **TorqueVerse**. 🏁

# 🚀 Getting Started

## 1. Clone The Repository

```bash
git clone https://github.com/Ebinezer-cloud/TorqueVerse-3D.git
```

## 2. Open The Project

```bash
cd TorqueVerse-3D
```

## 3. Start A Local Server

Because the project uses browser modules and PWA functionality, running it through a local HTTP server is recommended.

### Using Python

```bash
python -m http.server 8000
```

### Using Node.js

```bash
npx serve .
```

## 4. Open In Browser

Visit:

```text
http://127.0.0.1:8000
```

Then launch **TorqueVerse 3D**. 🚗💨
